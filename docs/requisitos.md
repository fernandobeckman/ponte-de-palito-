# Requisitos do projeto (definidos pela equipe)

Leia antes de propor qualquer peça, material ou mudança no projeto.

| requisito | valor | origem |
|---|---|---|
| Vão livre entre apoios | 500 mm | equipe, 2026-11-09 |
| Carga a resistir | 40 a 45 kg; projeto feito para 45 kg (441,29925 N) | equipe, 2026-11-09 |
| Aplicação da carga | concentrada, no meio do vão | equipe, 2026-11-09 |
| **Materiais** | **somente palito de picolé e cola branca**. Vale também para peças provisórias, como os espaçadores | equipe, 2026-11-09 |
| Limite de massa ou de número de palitos | nenhum | equipe, 2026-11-09 |
| Precisão dos números | até 5 casas decimais | equipe, 2026-11-09 |
