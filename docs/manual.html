Monte a ponte passo a passo

Cada passo mostra as peças novas em amarelo na imagem. Toque nas etiquetas para ver o número, o código, a medida e o ângulo de corte de cada palito, ou abra o passo no 3D para girar e ver de perto.

12 = número da peça (escreva a lápis na peça depois de cortar). B1 = código do formato: peças com o mesmo código são iguais. 3× na caixa amarela = quantas peças daquele código entram no passo. Toque na caixa para acender só essas na imagem. Marque Feito em cada passo para acompanhar o progresso. A marcação fica salva neste aparelho.
